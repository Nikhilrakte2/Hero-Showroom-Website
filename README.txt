
PRODUCT IMAGES: file names to use
==================================
Keep hero-shop.html and this "images" folder side by side:

  hero-shop.html
  images/
      hf-deluxe.jpg
      splendor-plus.jpg
      ...

Name each photo exactly as below (lowercase, .jpg). The website finds it automatically.
If a photo is missing, that card shows the engine size instead.

Tip: a side view of the bike on a plain or transparent background looks best.
Use .png if you have transparent images, then set  image: "images/xoom-160.png"  on that bike in hero-shop.html.
